Connect the files

REPS v1/
  index.html
  about.html
  css/
    style.css

Inside each page's <head>:

<link rel="stylesheet" href="css/style.css">

A shared stylesheet lets several pages use the same rules. MDN: external stylesheets.

Vocabulary

Selector
Chooses the elements targeted by a CSS rule.
Property
The aspect to change, such as text colour.
Value
The setting for that property.
Declaration
A property and value together, such as color: blue;.
Stylesheet
A file containing CSS rules.
h1 {              /* selector */
    color: blue;  /* property: value; */
}

color changes text colour; background-color changes the background. MDN: CSS basics.

When nothing changes

  1. Save the HTML and CSS.
  2. Check the actual filename and folder.
  3. Put the link in the head.
  4. Check braces, the colon and the selector.
  5. Refresh the correct page.

Ask your teacher to inspect your files if it still does not work.

Spacing vocabulary

Content
The text, image or other content inside the box.
Padding
Space inside the border.
Border
The edge surrounding content and padding.
Margin
Space outside the border.
Border-box
A sizing mode that includes padding and border within a declared width; margin remains outside.
main {
    max-width: 960px;
    margin: 0 auto;
    padding: 16px;
}

This caps the width, centres the container when there is spare horizontal space and adds internal breathing room. MDN: box model.
