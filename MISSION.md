# Mission: Learn web development through REPS

## Why
Build the REPS student club website for ICS 2102 while learning to explain, change and verify the code independently. Produce a complete, reliable project that meets the README's MVP requirements.

## Success looks like
- Explain the purpose of the HTML, CSS, JavaScript and PHP used in REPS.
- Make small changes independently and check their effects in the browser.
- Complete each day's README exit criteria, including a readable responsive interface on Day 2.

## Constraints
- Follow the six-day plan in README.md; the user identifies this session as Day 2.
- Use plain English, small practical exercises and feedback.
- Assess understanding through the user's answers and work; existing files do not prove mastery.

## Out of scope
- Features excluded from the README's semester MVP.
