2. Read one CSS rule

h1 {
    color: blue;
}

Selector: h1 chooses the heading elements. Property: color names what to change. Value: blue gives the setting. Together, color: blue; is a declaration.

Read this aloud: “For every h1 on this page, make the text blue.” CSS rules describe appearance; HTML supplies the content and structure. Source and recommended reading: MDN, Getting started with CSS.

3. Practise from memory

Write a rule that makes the heading blue. Try without looking at the example, then press Apply. This practice area changes only the preview below.

4. Make the change in REPS

  1. In VS Code, create a folder named css in the project root, beside index.html.
  2. Inside it, create style.css. Write your heading rule there.
  3. In index.html, add the following line inside <head>, before </head>:
<link rel="stylesheet" href="css/style.css">

rel="stylesheet" says what this linked file is for. href="css/style.css" gives its location, relative to index.html. One external stylesheet can serve several pages. Source: MDN external stylesheets.

Save both files. Open REPS Home and refresh. The REPS heading should be blue. If it isn't, check the filename, folder, link location and saved changes.

Once Home works, add the same link inside the head of about.html. Open About and check that its heading changes too. Keep both pages using the same CSS file.

Blue is a temporary learning colour. We will choose the project's design variables after you understand this connection.

5. Explain it and get feedback

  1. Which part of your CSS chooses the heading?
  2. Why did both Home and About change?
  3. If you wanted only the heading text to change colour, would you choose color or background-color?

Your teacher can inspect the actual files and help with anything unclear. Ask follow-up questions at any point.
