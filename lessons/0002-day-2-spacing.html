Give your content breathing room

One practical win: centre the main content and give it comfortable space without breaking narrow screens.

A box has inside and outside space

Content is the text or image. Padding is the space between that content and its border. Border is the edge around the box. Margin is space outside the border.

Imagine a framed picture: padding is breathing room inside the frame; margin separates the frame from neighbouring objects. Recommended reading: MDN box model.

A section's text touches its border. Which change addresses that?

Build one container

Type these rules into your site stylesheet. Read each comment and predict the result before refreshing.

* {
    box-sizing: border-box;
}

body {
    margin: 0;
}

main {
    max-width: 960px;
    margin: 0 auto;
    padding: 16px;
}

* selects all elements. border-box includes padding and border within a declared width. max-width caps the main box without forcing that width onto a small screen. margin: 0 auto sets top/bottom margins to zero and shares spare horizontal space between the sides.

padding: 16px adds internal space on all four sides. There is no fixed height: your content can grow. Source: MDN box model.

Put in three reps

  1. Observe: Add border: 1px solid red; inside the main rule temporarily. Open Home. Change padding from 16px to 32px. Which space changes? Restore 16px.
  2. Transfer: Without copying the main rule, write a rule for main section that gives each section 16px padding and 24px space below it. Hint: outside space uses a margin property.
  3. Verify: Resize Home and About to 320px wide using the browser's responsive tools. Check that text wraps and there is no sideways scrolling. Remove your debug border.

Change one thing at a time so the effect is clear. If the layout surprises you, tell your teacher what you predicted and what happened.
