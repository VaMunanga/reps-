## Knowledge

- [MDN: Getting started with CSS](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/Getting_started)
  Read for linking an external stylesheet and writing selectors and declarations. Primary reading for Day 2 lesson 0001; checked 2026-10-07.
- [MDN: The box model](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/Box_model)
  Read for content, padding, border, margin and box sizing in the next spacing exercise; checked 2026-10-07.
- [MDN: Responsive web design](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design)
  Read for flexible layouts and adapting pages to screen widths later in Day 2; checked 2026-10-07.
- [REPS README](README.md)
  Project scope, six-day schedule and acceptance criteria. Section 23 defines Day 2; sections 14 and 29 guide quality checks.
- [Day 1 HTML cheat sheet](DAY-1-HTML-CHEATSHEET.md)
  Existing local reference for page structure and the elements already used in REPS.
